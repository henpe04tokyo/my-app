# 点数ルールの仕様

実装は `src/utils/scoreCalculation.js`（テストは同名の `.test.js`）、`GameInputForm.jsx`、`Dashboard.jsx` の `addGameScore`。
ここを変えるときは、`CLAUDE.md` の「絶対に守ること」も確認する。

## 用語
- **グループ**: 1回の集まり（その日の卓）。複数の半荘を持つ
- **半荘**: `games[]` の1要素
- **持ち点（素点）**: 半荘終了時の4人の点数。合計は通常10万点
- **順位点（ウマ）**: `settings.rankPoints`（[1位,2位,3位,4位]、例 `[0,10,-10,-30]`）
- **pt**: 千点 = 1pt。`finalScores` はこの単位

## 1. 持ち点の入力
- 下2桁（100点未満）を省略する。`292` → 29,200点、`-3` → -300点
- 使える文字は数字と**先頭の `-`** だけ。桁数は符号を除き最大4桁（`sanitizeScoreInput`）。変換は `toRawScore`
- 入力欄の下に、変換後の点数を表示する
- 合計が10万点から1,000点を超えて離れると警告が出て、保存ボタンが無効になる（変換後の点数で判定）。
  リーチ棒が場に残った半荘は合計が足りなくなるので、2本以上だと引っかかる

## 2. 順位点の計算（`calculateFinalScoresFromInputs`）
- 持ち点の大きい順に順位を決める
- 2〜4位: `順位点[順位] − (30 − roundScore(持ち点))`（pt）。返し点は30000固定（`settings.returnPoints`。グループ設定にはない）
- 1位: 他の3人の合計の符号反転（ゼロサム）。1位の持ち点自体は計算に使わない
- 最後に `Math.round`
- `roundScore`（五捨六入）: 千点未満を、百の位が6以上なら切り上げ、5以下なら切り捨て。**マイナスも絶対値で行う**（-1,300 → -1、-1,500 → -1、-1,600 → -2）

## 3. 飛び賞
- 設定は行ごとに「飛んだ人」「飛ばした人」「ボーナス（10〜90、10刻み、pt）」。複数行も可（ダブロンなど）
- 順位点の計算の**後**に `finalScores[飛んだ人] −= amount`、`finalScores[飛ばした人] += amount`
- 追加時の順位回数（`rankingCounts`）は、飛び賞を加える前の `baseFinalScores` で順位を決める

## 4. 飛んだ人が最後に払った点数（`payment` / `paymentPoints`）
- 目的: 飛びで終わった局は、画面の点数が払う前のまま。持ち点は画面のまま入力し、払った分を飛び賞の行に入れて、計算に任せる
- 入力: 飛び賞の各行の任意項目。下2桁省略（`80` → 8,000点）。ロンなら放銃点（本場込み）、ツモなら飛んだ人の支払い分
- 前提: ツモのとき、飛んでない人の払いは画面の点数に反映済み。この想定は実運用で確認中
- 計算: `applyTobiPayments` が飛んだ人から引いて飛ばした人に足す（合計は変わらない）。結果が `adjustedInputScores`
- **同点判定・順位・順位点は、この反映後の点数で行う**（`GameInputForm` と `Dashboard.addGameScore` の両方で同じ関数を通す）
- 画面: 持ち点欄の下に反映後をプレビュー。反映後も0点以上なら注意を出す（保存は止めない）。飛んだ人／飛ばした人が未選択の行は保存できない。空欄なら何も反映しない
- リーチ棒（供託）は反映しない（飛ばした人が受け取る分は入らない）

## 5. 同点
- 反映後の持ち点が完全に一致したとき、`TieResolutionModal` で順位を指定する
- 指定どおりに並べ替えてから計算する（`buildReorderedInputsFromAssignments`）

## 6. チップ
- `chipRow.rankN`（枚数、空欄は20）、`settings.chipDistribution`（配点、既定300）
- `chipBonus = (枚数 − 20) × 配点 / 100`、`halfResult = finalResult + chipBonus`（`recalcFinalStats`）

## 7. 集計
- `finalResult` = 全半荘の `finalScores` を、プレイヤー列ごとに合計したもの（プレイヤー名で集計）

## 8. ログイン不要の精算計算ツール（`utils/quickCalc.js`）
- トップ（未ログイン）の計算ツール。入力は4人の持ち点（下2桁省略、`toRawScore` 経由）、順位点（5種類）、レート（1ptあたり円）
- 計算は `calculateFinalScoresFromInputs` をそのまま使う（原点25,000・返し30,000点固定）。収支（円）= スコア（pt）× 1ptあたりの円
- 同点は席順（上に入力した人が上位）。アプリ本体のような同点時の順位指定はない。飛び賞・チップは対象外
- 保存・送信はしない。ここを変えたら、`quickCalc.test.js` と `Landing.test.js` も確認する

## 保存される値
`games[]` のフィールドは [architecture.md](architecture.md) を参照。要点:
- `rawInputScores` / `inputScores` = 入力どおり、`adjustedInputScores` = 支払い反映後
- `baseFinalScores` = 飛び賞前、`finalScores` = 飛び賞後（これだけを集計に使う）

## 手計算の例
東 36,000 / 南 41,000 / 西 20,000 / 北 3,000 のとき、北が南に8,000点を払って飛び、飛び賞10。
- 入力: `360` `410` `200` `30`。飛び賞の行: 飛んだ人=北、飛ばした人=南、払った点数=`80`、ボーナス=10
- 反映後: 南 49,000 / 東 36,000 / 西 20,000 / 北 -5,000
- 順位点: 南 +69、東 +16、西 -20、北 -65
- 飛び賞（±10）を加えて `finalScores`: 南 +79、東 +16、西 -20、北 -75
